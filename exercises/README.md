# Exercises & Quizzes

Practice material for the Arena self-study course. **Suggested rhythm:**

- After each lesson → the matching quiz (closed book first!).
- Weekly → one build challenge from [practice-problems.md](practice-problems.md).
- Before starting a quiz → make sure you finished the corresponding lesson.

## 📁 Contents

| File | What it is | Use with |
|------|-----------|----------|
| [quiz-basics.md](quiz-basics.md) | 40 Q&A covering concepts, interface, arrivals, resources, flow control | Lessons 1–5 |
| [quiz-modeling.md](quiz-modeling.md) | 40 Q&A covering expressions, statistics, V&V, reports, tricky scenarios | Lessons 6–8 |
| [practice-problems.md](practice-problems.md) | 12 build-it-yourself model challenges with hints, checklists & solution guides | Lessons 3–9 |

## ✍️ How to take a quiz (seriously — it matters)

1. **Closed book.** Write answers on paper or in a separate file.
2. Score yourself honestly with the collapsible answers.
3. For every wrong answer: write one line — *what you thought vs. the truth*.
   Put those lines in your `mistakes-log.md`.
4. Re-take the quiz 3 days later. Anything below 90% → re-read that lesson.

## 🎯 Score guide

| Score | Meaning | Action |
|-------|---------|--------|
| 90–100% | Solid | Proceed to next lesson / harder challenge |
| 70–89% | Gaps | Re-read lesson sections for missed topics |
| < 70% | Re-learn | Re-do the lesson's examples in Arena, then retest |

## 💡 Practice priorities

If you're short on time, do in this order:

1. [practice-problems.md](practice-problems.md) #1–#4 (core modeling muscle)
2. [quiz-modeling.md](quiz-modeling.md) (statistics & V&V questions are where
   interviews/exams focus)
3. Everything else.
