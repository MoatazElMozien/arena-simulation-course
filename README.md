# Arena Simulation Software — Zero to Hero Self-Study Course

A complete, self-paced mini course to take you from never opening Arena to building,
verifying, and analyzing your own discrete-event simulation models.

## 🎯 What you will learn

By the end of this course you will be able to:

1. Explain what discrete-event simulation is and when it is the right tool.
2. Navigate the Arena interface and module palette with confidence.
3. Build models using **Create → Process → Decide → Dispose** and related modules.
4. Model resources, schedules, priorities, and queues correctly.
5. Control flow with batching, routing, sequences, and assignments.
6. Use expressions, variables, attributes, and basic Arena logic.
7. Set up run parameters, replications, and read Arena's reports.
8. Verify and validate a model so your results can be trusted.
9. Complete end-to-end case-study projects from scratch.
10. Test yourself with quizzes and build-it-yourself practice problems.

Work through the lessons **in order** — each builds on the previous one.

## ✅ How to use this course

1. **Read** the lesson top to bottom once without Arena open.
2. **Re-do** every example in Arena yourself — do not copy-paste, click it out.
3. **Answer** the practice questions at the end of each lesson *before* peeking at the answer.
4. **Mark off** the checkpoint at the bottom of each lesson only when you can do it unaided.
5. Periodically revisit [exercises/](exercises/README.md) to keep yourself sharp.

> 💡 **Tip:** Keep a plain text file called `mistakes-log.md` next to this course.
> Whenever a model does something surprising, write down what you expected vs what
> happened. That log will teach you faster than any tutorial.

## 🛠️ Requirements

- Arena Student/Educational or licensed version installed (14.x–16.x all work;
  screenshots and menu names may vary slightly by version).
- A Windows PC. No programming experience required.
- Optional but recommended: Excel (for data) and pen & paper for model sketches.
